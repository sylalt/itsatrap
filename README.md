# It’s a Trap — React website concept

Open dist/index.html directly for the compiled offline website.

Edit src/App.jsx and src/style.css in VS Code. Run `npm install` and `npm run build` to rebuild; `npm start` serves the site at http://localhost:3000.

Navigation: Home, 2026 Edition, Ethos, Archive, Through the Lens, Community, footer Contact. Mobile responsive. Archive category filtering, FAQ disclosure controls and suggestion downloads work locally.

Before launch: supply and verify date, venue, lineup, ticket URL, age policy, timings, accessibility details, support/reporting arrangements, historical records, approved images with photographer credits and portfolio URLs, press links, contact details and WhatsApp invitation. The ethos is proposed copy for organiser review. Monster artwork is an original CSS placeholder; archive graphics are not historical posters. No claims of verified safeguarding arrangements are made.

Suggestions currently download JSON only; no data is sent, stored or collected. Connect an appropriate service and publish a privacy notice before enabling submissions. Optional email is included only in the visitor's downloaded file.

React and React DOM are bundled for offline viewing; their licences are in LICENSES. No external fonts or image requests. This is a local preview concept, not a publicly deployed site.
